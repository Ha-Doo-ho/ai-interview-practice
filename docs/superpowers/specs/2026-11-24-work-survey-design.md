# 업무 행동 설문 시범 도입

사용자가 승인한 ② 사전 대안 비교와 ③ 반복 결과 활용을 새 회차에 도입한다. 기존 핵심 O-B01/O-B02/O-B03과 합쳐 5문항으로 구성한다. 새 문항 원문은 각각 “처리 방법을 선택해야 하는 업무에서는, 방법별로 예상되는 결과를 비교한다.”와 “비슷한 업무를 반복할 때, 여러 차례의 결과를 비교해 다음 처리 방법을 선택한다.”다.

모든 선택지의 문구를 표시하는 기존 6단계 동의형을 사용한다. 순서는 전혀 그렇지 않다 / 그렇지 않다 / 그렇지 않은 편이다 / 그런 편이다 / 그렇다 / 매우 그렇다. 경험 없음과 판단 어려움은 선택 점수 없이 별도로 기록한다. 중앙값이나 강한 비동의로 대체하지 않는다. 자동 기본 선택을 두지 않는다.

## 적용 방법과 범위

기존 전역 설문을 덮어쓰면 과거 형식 오표시와 근거 누락이 발생하므로, 새 문항집 `work-behavior-v2`를 명시 요청한 회차에 고정된 문항 정의를 저장한다. 브라우저의 새 연습은 이 버전을 요청하고, 구형 클라이언트나 버전 없는 기존 회차는 기존 6문항을 유지한다. 기존 회차에 새 문항을 추가하거나 기존 원문을 바꾸지 않는다.

새 문항에는 독립 ID O-PLAN-COMPARE/O-RESULT-LEARNING을 부여한다. 종합 입력에서 각각 계획/반복 결과 활용 주제에 자기보고로 연결한다. 기본 면접 B01/B02/B03의 검증된 행동 지표로 새 문항을 자동 승격하지 않는다. 공간지각과 조건 비교 신규 설문은 보류한다. 과거 선호·관점·순위 자료는 그대로 보존한다.

6단계는 프로젝트의 설계 선택이며 NCS·JOBDA의 공인 채점척도가 아니다. NCS 2025.12 개편 문제해결능력 표준의 대안 비교·평가와 성찰·피드백, JOBDA의 길 만들기/마법약 설명은 부분적인 주제 근거다. Pew 설문 지침을 참고해 라벨·순서·원문·버전을 보존하고, 시범 응답으로 해석과 응답 쏠림을 확인한다. 응답을 능력 점수·확률·거짓말 판단으로 변환하지 않는다.

## 검증

새/구 문항집의 생성·제출·재조회·게임 진입·종합 입력·완료 경계를 확인한다. 경험 없음/판단 어려움은 강약 선택과 배타적이며, 입력 유실 재시도에서 구분을 보존한다. 기존 사용자 DB와 외부 AI를 사용하지 않는다.
