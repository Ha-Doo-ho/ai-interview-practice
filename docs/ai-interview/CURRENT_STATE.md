- 종합 입력: 새 두 문항은 계획/반복 결과 활용의 자기보고 근거에만 연결한다. 신규 문항의 NCS·JOBDA 출처, 자체 미검증 문항이라는 범위와 결측 해석을 실제 모델 전달 구조에 포함한다. 새 설문을 작업기억/공간지각의 직접 측정으로 쓰지 않는다. 구형 회차의 프롬프트와 digest는 독립 검토에서 변경 전과 일치했다.
- 설계 지침 보존: [Pew 설문 문항 지침](https://www.pewresearch.org/writing-survey-questions/)을 참고해 선택지의 의미·표현·순서를 명확히 표시하고, 원문·척도·버전을 함께 보존한다. 6단계는 기존 응답과 일관성을 위한 프로젝트 결정이며 NCS·JOBDA의 공식 척도가 아니다. [NCS 2025.12 문제해결능력 표준](https://www.ncs.go.kr/web/job/contents/3.%20직업공통능력-문제해결능력.pdf)과 [JOBDA 공식 게임 설명](https://www.jobda.im/info/406)은 문항 주제의 부분적인 근거다. 능력 점수나 시범 도입의 효과를 입증한 자료로 제시하지 않는다.
