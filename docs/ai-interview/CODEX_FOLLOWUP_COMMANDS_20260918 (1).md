# Codex 후속 명령 — 문서 재수정과 검증 보류 해소

이 파일은 **명령 1~6을 한 개씩** Codex에 입력하기 위한 것이다. 한 명령의 결과를 받은 뒤 다음 번호를 입력한다. 여러 명령을 한 번에 붙이지 않는다. 최초 명령의 공통 규칙은 파일에도 보존하고 다음 명령에서 다시 읽게 한다.

준비할 자료:

- `AI_INTERVIEW_AUDIT_REPORT_20260918.md`: 작업별 F-01~16, H-01~06과 완료 기준.
- 이 파일 `CODEX_FOLLOWUP_COMMANDS_20260918.md`.
- 최신 검토자 `AI_INTERVIEW_REVIEW_LOG.md`: 기록 버전 8, 최신 18절. 기존 프로젝트의 동명 파일을 덮지 말고 별도 폴더에 놓는다.
- 로컬 Codex의 기존 결과 폴더 `docs/ai-interview/traceability-revision/20260917-151559-KST/`.

이 파일의 ‘실패’는 확인된 문서 완료 기준 미충족 또는 실제 실행 실패를 각각 명시하는 상태다. 미제출 증거, 미실행 검사, AI 미연동을 실패로 합산하지 않는다. 실제 기능 구현은 이번 명령에 포함하지 않는다.
