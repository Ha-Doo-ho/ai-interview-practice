# 면접 8문항 실행 재검증

2026년 11월 25일, 합성 계정과 격리 SQLite로 검사했다. 사용자 데이터베이스와 기존 서버를 변경하지 않았고 실제 AI 공급자를 호출하지 않았다.

- 전체 재실행에서 html/index.html의 자산 버전이 두 종류인 상태를 기존 통합 시험이 검출했다. 이전 수정에서 면접과 보고서 스크립트만 캐시 버전을 바꾼 것이 원인이었다. 모든 로컬 CSS·JavaScript 자산을 20261125-eight-interview로 맞췄다. 관련 통합 시험 3개를 먼저 통과한 뒤 전체 Python 539개와 frontend 155개를 다시 통과했다. 최초 실패 실행은 최종 통과에 포함하지 않는다.
- 독립 Astra 6.2 high는 기존 16문항 회차와 신규 8문항 회차를 각각 실제 API로 진행했다. 설문 5개 제출, 게임 8종 완료, 면접 8개 저장, 기본 모의 분석, 근거 연결, 종합 모의 분석, 최종 확정과 새 로그인 세션의 재조회를 확인했다. 회전 10개·길 만들기 10개·마법약 100개를 포함해 각 문항을 개별 제출했으며 진행 시간만 제어했다.
- 기존 회차는 문항 전환 전 직접 프롬프트 조회·종합·확정 요청이 409로 차단됐다. 전환 후 과거 질문 13개와 답변이 이력에 보존됐고 현재 고정 질문 8개만 사용했다. 추가 독립 회귀 시험 23개가 통과했다.
- 실제 브라우저에서도 구형 회차를 열어 현재 질문 8개·입력창 8개·새 7번 원문·오류 없음·답변 저장 원문을 확인했다. 별도 시험 서버와 탭은 종료했다.
- 보고서는 삭제한 문항이 반영된 8문항본에서 개발 모델 문단과 그림 설명, 첫 그림만 폭포수 모델로 바꿨다. 나머지 본문·표·출처·프롬프트 예시·세 설계 도해를 유지했다. 네이티브 Word 페이지 검사는 완료로 기록하지 않는다. 사용자의 요청에 따라 데스크톱과 Word 조작을 중단했다.
