# 다섯 게임 통합 계약 초안 — 2026-10-29

## 목표

한 로그인 사용자와 한 연습 회차에서 가위바위보 → 숫자 카드 → 요일 → 장소 → 버스 게임을 순서대로 진행하고, 각 게임의 조건과 실제 사건·결과를 저장해 보고서와 이후 AI 해석에 연결한다. 3~5번 게임은 공통 난이도를 한 번 선택하고 각 10문항으로 고정한다. 게임별 점수를 합산하거나 성격·채용 결과로 해석하지 않는다.

## 원본과 계산

- 새 회차에 게임 흐름/규칙 버전을 고정한다. 기존 완료 회차는 이전 완료 정책을 유지해 변경하지 않는다. 기존 미완료 회차에 적용할 정책은 서버에서 명시하고 실제 이전 기록을 유지한다.
- 난이도, 각 게임/문항 ID·버전·순서, 실제 A/B/C 제시 항목·순서와 제시/응답 시간 조건, 선택지·정답, 답변 또는 시간 초과, 서버 시각·결과를 저장한다. 아직 공개되지 않은 항목과 정답은 응답 전 공개하지 않는다.
- 각 게임은 0점에서 시작하고 서버가 실제 순서에 따라 정답 +10, 오답/시간 초과 -5, 최저 0점을 계산한다. 정답·오답·시간 초과와 미시작/중단은 구분한다. 통신 실패를 오답이나 완료로 바꾸지 않는다.
- 서버는 로그인·소유권·회차·버전·상태·시간과 예상 revision을 검증한다. 요청 결과가 불확실할 때 같은 멱등키와 내용으로 재확인한다. 원본, 파생 요약, 보고서 버전은 분리한다. 삭제 시 해당 원본과 파생 자료를 함께 무효화한다.

## 화면과 보고서

- 기존 페이지의 게임 흐름에 세 게임을 연결하며 원본 폴더는 보존한다. 현재 난이도·문항 수 선택 UI는 공통 난이도 선택 및 10문항 고정 흐름에 맞게 별도 통합 화면으로 조정한다.
- 다섯 게임의 상태·조건·원본 근거를 각각 표시한다. 기존 두 게임은 20초 3라운드이며 10문항 게임과 같은 분모가 아니다. 중단된 항목은 완료된 점수로 표시하지 않는다.
- 서버가 확정한 결과와 조건을 보고서에 참조 ID·버전과 함께 제공한다. 게임 내용을 기본 면접 추출기에 주입하지 않는다. 기본 추출이 고정된 이후 별도 통합 해석에서만 이용하며, 공급자 입력과 출력의 수치·출처를 서버 원본과 대조한다. 검증 실패와 AI 미사용은 구분한다.

## 구현 순서와 검증

1. 독립 게임의 규칙을 서버에서 재현하고, 생성·공개 단계·응답·타임아웃·10문항 점수·공통 난이도의 API 및 임시 DB 검사를 먼저 작성한다.
2. 기존 회차 및 순서 정책, 소유권·멱등성·삭제·중간 종료를 검사한다. 기존 게임 완료 흐름의 회귀를 확인한다.
3. 현재 화면에 세 게임과 시작·재개·실패 재시도를 연결한다. 서버 기록을 근거로 보고서를 구성하고 조건 및 문항별 기록을 표시한다.
4. 기본 면접 추출 이후의 별도 AI 해석 경계를 구현하고 실제 전송 없이 mock/test double로 수치·출처 및 격리 검사를 수행한다. 실제 AI 호출은 구성·비용 조건을 확인한 별도 검증으로 기록한다.
5. 합성 사용자로 로그인부터 다섯 게임→면접→보고서→재조회·삭제를 API와 브라우저에서 확인한다. 원본 harness를 실제 테스트에 연결하고 자동/수동, mock/live, 실패/차단을 기록한다.

현재는 계약 초안이며 위 기능을 구현하거나 실행한 기록이 아니다.
