# 선택형 자원 게임 시험 연결 — 2026-10-28

사용자 요청: 기존 자원 게임을 현재 사이트에서 시험하고, 문제가 있으면 플래그로 기존 흐름으로 복귀. 이것은 기존 과제의 시험 연결이며 역량 검사 타당화/신규 게임 설계가 아니다.

## 결정

- 서버 플래그 `RESOURCE_GAME_PREVIEW_ENABLED`, 기본 false. 공개 설정 조회 GET `/api/features`. 새 입력은 POST `/api/runs/{id}/resource-game-preview`에서 서버도 플래그 검사.
- 기존 두 게임 완료 후 추가로 선택하는 연습1+본3 과제. 기존 최종 확정의 필수 게임 수는 그대로 둔다. 완료된 회차를 다시 열지 않는다.
- 새 UI는 기존 게임 코드/화면 교체 없이 독립 `html/resource-game.js` 및 두 개의 영역(게임/보고서)에 연결. 서버의 실제 배분/조건 충족/유지·수정/미응답 기록을 표시한다. 분석이나 성격 점수로 표현하지 않는다.
- 원래 resource metrics는 기존 분석에서 참조되므로 선택형 과제 진행 후 기존 보고서가 오래된 상태가 되면 기존 재생성 절차를 따른다. AI 호출 없이 게임 원본 결과를 볼 수 있다.
- 같은 회차 잠금은 기존 game lock과 분리하여 게시하고 다른 모듈에는 합쳐 전달한다. 계정/회차 전환 시 이전 응답 무시. 불확실한 요청은 같은 멱등키로만 재시도하며 새로고침 후에도 보존.
- 플래그 OFF는 추가 입력/진입을 차단하고 기록은 보존한다. 코드 복구는 변경 전 백업과 변경 후 해시를 대조하고 사용자의 이후 편집이 있으면 덮어쓰지 않는다. DB는 복구 대상에서 제외.
- 기존 보고서 표시 검사 4건과 실제 AI 연결 설정은 이번 시험 연결 범위 밖이다.
