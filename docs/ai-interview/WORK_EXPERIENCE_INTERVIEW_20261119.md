# 업무 경험 면접 보완 — 2026-11-19

## 요청과 유지 판단

사용자는 공간 배치와 반복 업무 경험 문항을 반영하되, 기존 문항이 관련 있거나 더 유용하면 유지하도록 요청했다. 나 알아보기의 동의 척도에 관해서는 설명을 요청했으므로 설문 정의와 척도는 변경하지 않았다.

- B01은 다른 사람에게 어떤 정보를 얻고 결정에 반영했는지를 묻는 유일한 기본 문항이며 O/P-B01 설문과 연결된다. 공간 배치 질문으로 대체하면 이 내용을 잃으므로 유지했다. 구 resource-bridge 연결을 현행 five-game-v2에서 실행되는 게임 연결이라고 주장하지 않는다.
- B02는 목표·제약에 따른 자원 배분, B03은 새 정보에 따른 선택 재검토를 묻는다. 새 두 주제와 역할이 달라 유지했다.
- 기존 작업기억 경험 면접은 동시에 다루는 정보와 유지/변경 조건 구분을 묻는다. 원문·ID·버전·답변을 유지했다.
- 따라서 기존 질문을 덮어쓰지 않고 승인된 두 주제 각각 경험 질문 1개와 후속 3개를 추가했다. 기본 면접 3개, 선택 면접 13개(기존 5 + 추가 8)가 된다. 새 질문은 자체 경험 질문이며 공식 검사 문항이나 검증된 능력 평가 도구로 표시하지 않는다.

## 적용

- `app/supplemental_interview.py`: spatial-work-interview-v1, repeated-work-interview-v1 그룹과 독립 부모 질문을 추가. 기본 분석 행동 ID를 임의로 부여하지 않는다.
- 새 five-game-v2 회차에 자동 포함한다. 기존 진행 회차는 텍스트 면접의 **이 회차에 빠진 업무 경험 문항 추가**로 없는 ID만 추가한다. 기존 작업기억만 있는 회차도 지원한다. 완료 회차는 읽기 전용이다.
- 각 문항 저장·수정·재조회·건너뛰기·답변 없음, 보고서 미리보기 및 확정 원문 내보내기를 지원한다.
- 화면은 **업무 경험 면접 · 선택 답변**으로 표시하며 요청 변경/공간 배치/반복 업무별로 질문과 후속 번호를 구분한다. 학업·프로젝트·일상 사례도 가능하다.
- 능력 점수, 기본 면접 AI 입력, 기본 면접 완료 조건을 변경하지 않는다. 기존 DB 마이그레이션·운영 회차 직접 변경·live AI 호출 없음.
- 정적 파일 캐시 버전은 20261119-work로 통일했다.
