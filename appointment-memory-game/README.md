# 약속 정하기 · 요일·장소·버스 기억력 게임

현재 배포된 사이트의 소스 코드입니다. HTML, CSS, JavaScript로 제작했으며, 별도의 npm 패키지 설치 없이 실행할 수 있습니다.

## 실행 방법

1. ZIP 파일을 압축 해제합니다.
2. VS Code에서 `appointment-memory-game` 폴더를 엽니다.
3. 터미널에서 다음 명령을 실행합니다.

```bash
python start_game.py
```

Windows에서 `python` 명령을 사용할 수 없다면 다음을 실행합니다.

```powershell
py -3 start_game.py
```

4. 브라우저에서 http://localhost:8000 을 엽니다.
5. 종료하려면 터미널에서 Ctrl+C를 누릅니다.

Python 대신 VS Code의 Live Server를 사용하는 경우 `dist/index.html`에서 Open with Live Server를 선택해도 됩니다. JavaScript 모듈을 사용하므로 HTML 파일을 더블클릭하는 대신 HTTP 서버로 열어야 합니다.

## 파일 구성

- `dist/index.html`: 웹 페이지 기본 구조
- `dist/style.css`: 화면 디자인 및 반응형 스타일
- `dist/app.js`: 게임 선택, 화면 전환, 제한시간, 채점, 결과 표시
- `dist/core.mjs`: 난이도별 규칙, 무작위 문제 생성, 시간 단계 및 점수 계산
- `dist/town.mjs`: 장소 게임 지도 및 건물 그림
- `tests/core.test.mjs`: 게임 규칙과 문제 생성 검사
- `start_game.py`: 로컬 실행용 Python 서버

## 현재 게임 규칙

| 게임 | 쉬움 | 어려움 |
|---|---|---|
| 요일 정하기 | 각자 3개 / A·B·C 각 3초 / 응답 6초 | 각자 4개 / 각 1.5초 / 응답 3초 |
| 장소 정하기 | 각자 3개 / 각 3초 / 응답 5초 | 각자 4개 / 각 1.5초 / 응답 3초 |
| 버스 기억하기 | 각자 2개 / 각 3초 / 응답 5초 | 각자 2개 / 각 1.5초 / 응답 3초 |

요일·장소는 세 사람의 공통 항목 하나를, 버스는 누구도 타지 않는 번호 하나를 고릅니다. 문제는 매번 무작위로 생성됩니다.

- 문항 수: 6·10·20문항
- 시작 점수: 0점
- 정답: +10점
- 오답·시간 초과: −5점, 최저 0점
- 문항 수와 관계없이 배점은 동일합니다.

## 규칙 변경

`dist/core.mjs`의 `RULES`에서 `count`는 각 사람에게 제시하는 항목 수, `reveal`은 A·B·C의 제시 시간, `answer`는 응답 제한시간입니다. 시간 단위는 밀리초입니다.

## 테스트

Node.js가 설치되어 있다면 프로젝트 폴더에서 실행합니다. Node.js는 게임 실행에는 필요하지 않습니다.

```bash
node --test
```

## 데이터 및 실행 환경

이 코드는 브라우저에서 동작하는 독립형 게임입니다. 별도 데이터베이스, API 서버, AI 분석 또는 로그인 기능은 포함하지 않습니다. 결과는 새로고침하면 사라집니다. 배포 사이트의 ChatGPT 로그인 화면은 호스팅 서비스가 제공하는 것으로, 로컬 실행에는 필요하지 않습니다.
