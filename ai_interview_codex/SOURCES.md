# 자료와 가정

## 사용자가 제공한 자료

- `AI_역량검사_도움_서비스_프로젝트_계획서_수정본.docx`: 텍스트 면접 중심 MVP, 맞춤형 연습·피드백, 기록 관리, 서버/DB/API 역할, 개발 스택 제안을 참고했다. 원본 파일은 수정하지 않았다.
- 대화에서 제시한 네 입력 화면: 6단계 순서형, 자기·상상한 타인 관점 쌍, 방향·정도 슬라이더, k개 우선순위 선택이라는 **입력 형식**을 확인했다. 이 화면만으로 상용 검사의 역량 매핑·점수 산식은 알 수 없다.
- 이후 대화의 합의: 근거 일치도와 추가 연습 방향, 강도 원형 보존, 같은 행동끼리의 조건부 비교, 실제 관찰과 자기보고 구분을 제품 목적에 반영했다.

기존 영상/커뮤니티 글에서 언급된 상용 검사 채점 방식은 이 설계의 확정 사실로 채택하지 않았다. 부정적인 단어, 응답 시간, 설문-게임 차이를 일반적인 감점 공식으로 구현하지 않는다.
